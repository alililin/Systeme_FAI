# Système interactif inspiré d’un fournisseur d’accès Internet

## Présentation du projet
Ce projet a consisté à développer un système interactif inspiré des services proposés par les fournisseurs d’accès à Internet (FAI).

L’objectif principal était de concevoir une interface permettant aux utilisateurs de configurer et gérer certains paramètres réseau dans un environnement simulé.

Le projet permettait également de comprendre les bases de l’administration réseau, des services réseau et de l’interaction utilisateur-système.



# Objectifs du projet

## Objectifs principaux
- Comprendre le fonctionnement des réseaux
- Simuler des services réseau
- Développer une interface interactive
- Gérer des paramètres réseau
- Comprendre l’administration réseau

## Objectifs techniques
- développer une interface utilisateur
- manipuler des paramètres réseau
- simuler des services d’un FAI
- comprendre les échanges réseau



# Contexte

Les fournisseurs d’accès Internet permettent aux utilisateurs :
- d’accéder au réseau
- de configurer leur connexion
- de gérer certains paramètres réseau

Ce projet avait pour objectif de reproduire une partie de ces fonctionnalités dans un environnement simplifié.
